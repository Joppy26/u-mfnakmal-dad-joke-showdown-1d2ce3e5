Entry for the [Dad Joke Showdown bounty](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) on make.fun.

## The joke

> My son asked why I keep a pencil behind my ear. I said, "In case I ever need to draw the line."

## How it works

`main.ts` writes the joke, exactly as written, to `/output/entry.txt`. The
output is fully deterministic: the text is fixed in the source, so every run
produces byte-identical output.

Run it with:

```sh
node main.ts
```
